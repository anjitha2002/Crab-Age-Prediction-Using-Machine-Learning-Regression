# Crab-Age-Prediction-Using-Machine-Learning-Regression

## Project Description

This project predicts the age of crabs using physical measurements such as length, diameter, height, weight, and other body-related features. Different machine learning regression algorithms are trained and evaluated to identify the best-performing model.

The project includes data preprocessing, categorical data encoding, feature scaling, model training, model evaluation, model comparison, and prediction on unseen test data. Among the models tested, Gradient Boosting Regressor achieved the best performance based on MAE and R² score.
